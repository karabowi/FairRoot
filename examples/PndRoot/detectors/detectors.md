Folder Detectors
================

Contains the sub-detectors specific code for the different detector components of the PANDA experiment:

- **disc:**     DiscDIRC
- **drc:**      BarrelDIRC
- **dsk:**      old implementation of DiscDIRC
- **emc:**      Electromagnetic Calorimenters (Backward, Barrel, Forward, Shashlik)
- **ftof:**     Forward Time-of-Flight
- **fts:**      Forward Tracking Stations
- **gem:**      GEM Detector
- **hyp:**      Hyper Nuclear Setup
- **hypGe:**    Hyper Nuclear Setup Germanium
- **lmd:**      Luminosity Detector
- **mdt:**      Muon Detector
- **mvd:**      Micro Vertex Detector
- **passive:**  Passive Components (Cave, Magnets, Beam Pipe)
- **rich:**     Ring Imaging Cherenkov Detector
- **scitil:**   Barrel Time-of-Flight system (Scintilating Tile Detector)
- **sds:**      Semiconductor Detector Systems (base clases for MVD and LMD)
- **stt:**      Straw Tube Tracker
